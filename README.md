# Sales Performance Analysis Dashboard

This project is a Power BI dashboard created to analyze sales performance, profit trends, customer segments, payment modes, and category-wise sales insights.

## Features

- KPI Cards
- Sales Analysis
- Profit Analysis
- Category-wise Insights
- Regional Filters
- Customer Segment Analysis
- Payment Mode Analysis
- Interactive Dashboard

## Tools Used

- Power BI
- Excel / CSV Dataset

## Dashboard Insights

- Technology category generated high sales
- Consumer segment contributed maximum sales
- COD and Online payments were highly used
- Profit and sales trends changed over time
- Regional filters help analyze performance by location
